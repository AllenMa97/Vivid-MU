# VividMU 视频处理管道

VividMU 是一个智能化的视频处理管道，通过三个步骤从原始视频中提取最有价值的内容，特别适用于长时间视频的自动剪辑和摘要生成。

## 架构概览

```
原始视频 → Step 1 (粗粒度过滤) → Step1输出文件夹 → 
Step 2 (语义过滤) → Step2输出文件夹 → 
Step 3 (AI编辑) → Step3输出文件夹 → 最终视频
```

## Step 1: 粗粒度过滤器 (Coarse Filter)

### 目的
从原始视频中快速识别和提取有意义的片段，去除明显不需要的内容。

### 主要功能
- **帧特征提取**: 使用 dHash 和直方图分析视频帧的视觉特征
- **音频特征提取**: 分析响度、零交叉率(ZCR)、能量变化和节拍检测
- **片段分割**: 将视频按场景和音频变化分割成多个片段
- **初步评分**: 基于视觉和音频特征为每个片段打分
- **去重处理**: 移除重复或相似度过高的片段
- **稳定性检测**: 识别画面稳定且质量较好的片段

### 技术细节
- 使用 dHash 算法检测图像相似性
- 音频特征包括响度、零交叉率、能量变化和节拍检测
- 基于阈值的片段合并算法
- 多权重融合评分系统

### 输出
保留在 `step1_output` 目录中，包含经过初步筛选的视频片段。

## Step 2: 语义过滤器 (Semantic Filter)

### 目的
对 Step 1 输出的片段进行更深入的语义分析，识别内容的重要性和相关性。

### 主要功能
- **人脸识别**: 检测片段中的人脸数量和大小，优先保留有人像的片段
- **语音检测**: 识别对话和语音内容，评估语音比例和密度
- **场景多样性**: 分析场景变化，避免过多相似场景
- **细粒度过滤**: 基于人脸、语音、场景等多维度特征进行评分
- **语义总结**: 生成每个片段的语义摘要，便于后续处理

### 技术细节
- 集成深度学习人脸检测模型
- 语音活动检测(VAD)技术
- 场景变化检测算法
- 多维度加权评分系统

### 输出
保留在 `step2_output` 目录中，包含经过语义分析和精选的视频片段。

## Step 3: AI视频编辑器 (AI Video Editor)

### 目的
将 Step 2 精选的片段组合成最终的高质量视频，并应用智能编辑效果。

### 主要功能
- **智能转场**: 基于场景变化和运动分析，自动选择合适的转场效果
- **AI增强**: 使用阿里云AI服务进行色彩校正、对比度调整等
- **动态剪辑**: 根据内容节奏调整剪辑点，实现流畅的观看体验
- **音效处理**: 应用背景音乐、音量标准化等音频处理
- **特效应用**: 根据内容特点添加适当的视觉特效
- **节奏同步**: 确保视觉效果与音频节奏同步

### 技术细节
- 阿里云视觉语言模型(Qwen-VL)进行内容理解
- 时间序列分析识别最佳时刻
- 智能转场效果选择
- 基于内容的节奏感知剪辑

### 输出
保留在 `step3_output` 目录中，包含最终的编辑完成视频。

## AI增强特性

### 时间序列理解
不仅分析单帧，还理解视频的时间序列特征，能够识别连续动作和事件发展。

### 宠物表情识别
专门优化识别宠物表情丰富的时刻，适用于宠物视频的自动剪辑。

### 情感峰值检测
识别视频中最吸引人的关键时刻，如笑声、欢呼声或其他情感表达。

### 动态节奏调整
根据视频内容自然节奏调整剪辑速度，确保最终输出的流畅性和观赏性。

## 目录结构

```
project_root/
├── data/
│   ├── input/           # 输入视频文件
│   └── output/          # 输出结果
│       ├── step1_output/ # Step 1 输出
│       ├── step2_output/ # Step 2 输出
│       └── step3_output/ # Step 3 输出
├── src/                 # 源代码
│   ├── coarse_filter.py # Step 1 实现
│   ├── semantic_summarizer.py # Step 2 实现
│   ├── step3_editor.py  # Step 3 实现
│   └── ai_video_editor.py # AI视频编辑器
└── README.md           # 本文件
```

## 使用方法

1. 将待处理的视频文件放入 `data/input/` 目录
2. 运行主处理脚本启动三步管道
3. 查看 `data/output/` 目录下的各步骤输出结果
4. 最终视频位于 `data/output/step3_output/` 目录

## 技术栈

- Python 3.x
- OpenCV - 计算机视觉处理
- Librosa - 音频分析
- FFmpeg - 视频编解码
- 阿里云视觉语言模型 - AI内容理解
- Face Recognition - 人脸检测
- PyDub - 音频处理

## 特色功能

- **自适应处理**: 根据视频内容自动调整处理策略
- **多策略支持**: 支持社交、事件、探索等多种处理策略
- **智能评分**: 多维度评分系统确保最佳内容被保留
- **高效处理**: 并行处理架构提高处理效率
- **AI驱动**: 先进的AI模型提供内容理解和编辑能力
